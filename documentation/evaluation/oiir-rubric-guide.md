# OIIR manual scoring guide

Score each dimension from 0 to 2. Read responses in a random order where practical and
hide the expected total. A second scorer should use the same guide independently.

## Factual accuracy

- **2:** Indicator values and classifications agree with the supplied summary; no
  unsupported factual claim materially changes the interpretation.
- **1:** Minor imprecision or omitted qualifier, but the central interpretation remains
  usable.
- **0:** Incorrect value, reversed threshold/classification, or invented fact that could
  mislead a user.

## Logical coherence

- **2:** Inference and recommendation are proportional to the cited evidence and clearly
  acknowledge mixed or limited signals.
- **1:** Reasoning is understandable but contains a weak link, overconfident tone, or
  unexplained jump.
- **0:** Recommendation contradicts the observations or has no traceable connection to
  them.

## Completeness

- **2:** All four named OIIR sections are present and each performs its intended role.
- **1:** All headings are present but one section is empty/redundant, or one heading is
  missing while its function appears elsewhere.
- **0:** Two or more stages are absent or the output is not recognisably OIIR-structured.

## Transparency benchmark

- **2:** A non-specialist can trace the recommendation through named values and
  plain-English interpretations; uncertainty and caution are visible.
- **1:** Some traceability is present, but jargon, vague references, or missing caveats
  reduce interpretability.
- **0:** The output is effectively an unsupported recommendation or opaque score.

## Reporting

Calculate each sample total out of eight, the overall mean/median/range, and dimension
means. If two scorers participate, report exact-score agreement by dimension and an
appropriate reliability statistic only if sample size and assumptions are defensible.
Disagreements should be resolved only after independent scores have been preserved.
